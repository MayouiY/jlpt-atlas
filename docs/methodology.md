# 方法说明

## 1. 数据来源与合并

| 部分 | 来源 | 覆盖 |
|---|---|---|
| 言语知识・阅读 | jlptpracticetest.com（公开页面，robots.txt 允许） | N1 2010-12 – 2024-12（28 场）、N2 2010-07 – 2024-12（29 场） |
| 言语知识・阅读（补缺） | MOJiTest（用户本人 PRO 账号，浏览器内读取） | N1 2010-07、2024-12、2025-07、2025-12、2026-07；N2 2018-12、2021-12、2025-07、2025-12、2026-07 |
| 听力 | MOJiTest | 全部 64 场（N1/N2 各 32 场） |
| 答案核对 | MOJiTest 全部场次的答案序列 | 与 jlptpracticetest 按题号对齐比对 |
| 题型构成与考查目标 | jlpt.jp 官方「問題の構成」与 2022 年 N1 听力题量调整公告 | — |

合并规则：

- 某场若有 MOJiTest 的完整数据，则言语知识・阅读部分采用 MOJiTest；否则采用 jlptpracticetest。
- jlptpracticetest 个别场次的阅读题题号录入倒退（如编成 17–19），按大题顺序顺延修正。
- 两来源答案不一致（52 题，以★排序题和阅读为主）时默认采用 MOJiTest，并记录另一答案（`alt_answer_index`），前端标注“答案存疑”；确认 MOJiTest 有误的题目写在 `data/seed/answer-overrides.json`。
- MOJiTest 个别场次听力题号重复（如两个“3番”），按出现顺序重新编号。

## 2. 考点标注

### 语法（`data/seed/grammar.yaml`）
- 615 条：N1/N2 句型为主，另有常作为选项出现的 N3–N5 基础句型、敬语动词与句式、授受/使役/被动、接续词、指示词、副词。
- 每条一个正则；匹配前做 NFKC 规整、去空白与括号。多个句型重叠时保留最长的匹配（同长按词典顺序），所以「ないではいられない」只记为「ずにはいられない」而不会再记「てはいられない」。
- 适用范围：语法形式判断、文章语法用正确选项（干扰项另记为 distractor）；★排序题用四个片段；即时应答用台词。后两者是长文本，跳过标记为 `b: true` 的基础句型以减少噪声。
- 覆盖率：语法形式判断与文章语法共 1,000 题，71% 的正确答案匹配到至少一个句型；其余多为助词或内容性表达（文章语法题另有“文章语法功能”兜底分类）。`npm run report:untagged` 列出未匹配项。

### 词汇・汉字
- 汉字读音、表记、选词填空、近义替换、用法题的考查词，经 kuromoji 还原为原形作为词汇考点，并按词性归类（名词、动词、复合动词、い/な形容词、副词、拟声拟态词、外来语等）。
- 汉字读音题：把正确读音与每个干扰项分别做“去浊点 / 去促音 / 去拨音 / 拗音转直音 / 去长音”规整，若全部规整后相同，则差异所在的那一层就是考查的读音特征；否则记为“其他读音/音训混淆”。另标注考查词是训读词还是音读熟语。
- 表记题中只出现在干扰项里的汉字记为该汉字的“干扰项”出现（形近字/同音字）。

### 阅读・听力的信息提取方式
- 阅读按题干问法归入 14 类（画线部含义、理由、作者主张、作者对特定话题的看法、具体信息、A/B 比较、条件匹配、文书主旨、指示内容、目的、心情、内容一致、概括补全、其他）。
- 听力按旁白的提问句归入 23 类（如课题理解・最先要做的事 / 接下来做什么 / 必须做的事；要点理解・理由 / 最重要的一点 / 问题点；概要理解・主题 / 主张；综合理解・比较后选择等）。场景取开场白“〜で〜が話しています”中的地点；即时应答按台词判定话语功能（请求、劝诱、道歉、称赞、不满、传闻等）。

## 3. 复现规律

- 时间轴为已举行场次的序号（2010-07 = 1，…，2026-07 = 32；2020-07 取消不计）。
- 对每个考点、每个级别统计出现场次，相邻两次出现的间隔（场）的均值、中位数、最小、最大与变异系数（CV）。
- 规律类型：从未 / 仅一次 / 两次 / 规律复现（≥3 场且 CV ≤ 0.5）/ 不规律复现。典型周期取间隔中位数；距上次出现的场数 + 1 ≥ 典型周期时视为“按周期到期”。

## 4. 预测与回测

- 存在型考点（语法、词汇、汉字、构词）：对每个候选考点在每一场 t 计算特征，只用 t 之前的数据：
  1. 平滑出现率 =（出现场次 + α·同类平均出现率）/（t + α），α = 4；
  2. 近期加权出现率（衰减 λ = 0.8）；
  3. 到期程度 = 距上次出现 ÷ 平均间隔（上限 3）；
  4. 上一场是否已考；5. log(1 + 出现场次)；6. 是否从未出现。
- 用带 L2 正则的逻辑回归拟合（第 6 场起的全部样本），输出下一场的出现概率。词汇、汉字只有在首次出现之后才进入候选集，避免用到未来信息。
- 题型类考点（阅读/听力问法、场景、话语功能、读音特征、文章语法功能）每场都会出现，给出近期加权（λ = 0.7）的预计题数。
- 回测：对最近 10 场逐一“只用之前的数据训练 → 预测 → 与实际对照”，报告 Top-K 命中率（推荐中实际出现的比例）、召回率，并与“按历史出现场次排序”和“随机抽取”比较。结果：语法 Top-10 命中率 N1 17.0%、N2 20.0%，随机约 3.5%；词汇与汉字几乎不可预测。

## 5. 局限

- 真题来自社区整理/回忆版本，个别题目可能与原卷不同；答案冲突处已标注。
- 规则标注会有少量误判与漏判；句型词典与分类规则都可在 `data/seed/` 与 `scripts/lib/` 中修改后重建。
- 预测只反映历史统计规律，官方并未承诺任何出题周期。
